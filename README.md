A fresh-momentum scalper for pump.fun paper trading. The bot buys a coin only after it shows real buy pressure (price up over its last 8 trades, mostly buys), then exits fast: +35% take profit, −18% stop loss, a trailing stop once in profit, and a hard time stop. Paper trading only — no real funds, no network, fully deterministic.

## Run it

```sh
node main.ts
```
